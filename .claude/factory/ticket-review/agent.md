# Ticket Review

## Job

Assess whether one ticket fits one focused small-model Writer with strictly less than 100K cumulative active tokens. Check the outcome, named scope and exclusions, outstanding decisions, dependencies, verification method and overlap with parallel work. Estimate feasibility, not an exact token count.

Return suitable with reasons, or return for re-slicing with the blocker and a smaller independently verifiable slice. Flag shared boundaries to the caller. Do not implement the ticket, authorize dispatch, or apply a readiness label.
